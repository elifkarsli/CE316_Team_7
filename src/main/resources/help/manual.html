IAE User Manual

What Is IAE?

IAE is an automated programming assignment evaluation application. It helps instructors and evaluators run student submissions with predefined language configurations, compare produced output with expected output, and review results in a consistent way.

The usual workflow is: create a configuration, create or open a project, run the project, then read the results. Configurations define how programs are compiled and executed. Projects define what will be evaluated.

Creating A Configuration

A configuration describes how a specific programming language or execution environment should be handled. For example, a Java configuration can use javac Main.java as the compile command and java Main as the run command. A Python configuration can be marked as interpreted and use python3 main.py as the run command.

  1. Open the Configurations screen.
  2. Select New.
  3. Enter a clear name, such as Java 17 or Python 3.
  4. Enter the source file name expected from submissions.
  5. Enter the compile command if the language must be compiled before execution.
  6. Enter the run command used to execute the program.
  7. Enable Interpreted language when the language does not need a compile command.
  8. Select Save.

Configuration Fields

Field Description
Name The display name shown in the configuration list and project setup screens.
Source file The source file expected in a submission, such as Main.java or main.py.
Output file Optional output file name if the submitted program writes its result to a file.
Compile command The command used before running the program. It is required for compiled languages.
Run command The command used to execute the submitted program after compilation, or directly for interpreted languages.
Arguments Optional command-line arguments passed while running the program.
Expected output path Optional path to the expected output used when comparing the program result.
Interpreted language When selected, the compile command is not required.
Required fields are Name, Source file, and Run command. Compile command is also required unless Interpreted language is selected.

JSON Import And Export

JSON import and export are used to share configurations or move them between computers. Export creates a JSON file from a selected configuration. Import reads a JSON file and adds the configuration to the application.

Exporting A Configuration

  1. Select a configuration from the table.
  2. Select Export.
  3. Choose where to save the JSON file.
  4. Confirm the save operation.

Importing Configurations

  1. Select Import.
  2. Choose a .json file.
  3. The file may contain one configuration object or a list of configuration objects.
  4. After import, check the configuration table for the newly added records.

Example JSON:

{
  "name": "Python 3",
  "compileCommand": null,
  "runCommand": "python3 main.py",
  "sourceFileName": "main.py",
  "outputFileName": null,
  "interpreted": true,
  "arguments": null,
  "expectedOutputPath": "expected/output.txt"
}
If the selected JSON file is broken, empty, duplicated, or missing required fields, the application should show an error message instead of creating an invalid configuration.

Creating A Project

A project groups the information needed for an evaluation run. It normally contains a project name, a submission location, optional expected-output files, and the configuration that matches the language of the submissions.

  1. Open the project screen.
  2. Select New Project or the create action provided by the screen.
  3. Enter the project name.
  4. Select the folder that contains student submissions or source files.
  5. Select the expected output file or expected output folder if output comparison is required.
  6. Choose the configuration that matches the submissions.
  7. Save the project.

Running A Project

  1. Open the saved project.
  2. Confirm that the selected configuration, submission path, and expected output path are correct.
  3. Select Run or Start Evaluation.
  4. Wait until all submissions have been processed.
  5. Open the results screen to review the generated statuses and messages.

Reading The Results Screen

The results screen shows what happened during evaluation. Read each row by checking the submission name, the status, and any message produced during compile, run, or output comparison.

Status Meaning
Accepted The program ran successfully and matched the expected output.
Compile error The compile command failed, the source file was missing, or the compiler reported an error.
Runtime error The program started but crashed, exited with an error code, or could not complete normally.
Wrong output The program ran successfully, but the actual output did not match the expected output.
Timeout The program took too long and was stopped before it completed.
Missing file A required source, input, output, or expected-output file could not be found.
Configuration error The selected configuration is incomplete or contains a command that cannot be executed.

Error Messages

Message What It Means What To Check
Configuration name is required. The configuration was saved without a name. Enter a unique, descriptive name.
Source file name is required. The application does not know which submitted source file to run. Enter the expected file name, such as Main.java.
Run command is required. No execution command was provided. Enter the command that starts the program.
Compile command is required for compiled languages. The configuration is marked as compiled but has no compile command. Enter a compile command or select Interpreted language.
Configurations could not be imported. The selected file could not be read as a valid configuration JSON file. Check that the file is valid JSON and includes all required fields.
Configuration could not be deleted. The selected configuration could not be removed. Check whether it is used by a project or whether the configuration file is writable.

Running The Application

IAE is a JavaFX application managed with Maven. From the project root, use: 

mvn javafx:run

To compile the project and run tests, use: 

mvn test

Make sure Java 17 or a compatible JDK is installed before running the application.
