IAE User Manual

What Is IAE?

IAE is an automated programming assignment evaluation application. It helps instructors or evaluators run submitted source files with predefined language configurations, compare outputs, and read evaluation results in a consistent way.

A configuration describes how a specific programming language or execution environment should be handled. For example, a Java configuration can include a compile command such as javac Main.java and a run command such as java Main.

Creating A Configuration

  1. Open the configuration management screen.
  2. Select New.
  3. Enter a clear name, such as Java 17 or Python 3.
  4. Enter the source file name expected from submissions.
  5. Enter the compile command if the language must be compiled.
  6. Enter the run command used to execute the program.
  7. Enable Interpreted language for languages that do not need a compile command.
  8. Select Save.

Configuration Fields

Field Description
Name The display name of the configuration.
Source file The source file expected in a submission, such as Main.java or main.py.
Output file An optional generated output file name, if the execution process creates one.
Compile command The command used before running the program. This is required for compiled languages.
Run command The command used to execute the submitted program.
Arguments Optional command-line arguments used during execution.
Expected output path Optional path to the expected output used for comparison.
The application stores configurations in data/configurations.json.

Running The Project

The project is a JavaFX application managed with Maven. From the project root, use: 

mvn javafx:run

To compile the project and run tests, use: 

mvn test

Make sure Java 17 or a compatible JDK is installed before running the project.

Reading Results

Evaluation results should be read by checking whether each submission compiled, ran successfully, and produced the expected output. A successful result means the configured commands completed correctly and the produced output matched the expected output.

Status Meaning
Compile error The compile command failed or required files were missing.
Runtime error The program started but failed while running.
Wrong output The program ran, but the output did not match the expected result.
Accepted The program ran successfully and matched the expected output.

JSON Import And Export

Export

  1. Select a configuration from the table.
  2. Select Export.
  3. Choose where to save the JSON file.

Import

  1. Select Import.
  2. Choose a JSON file containing one configuration or a list of configurations.
  3. The imported configurations are added with new IDs.

Example JSON:

{
  "name": "Python 3",
  "compileCommand": null,
  "runCommand": "python3 main.py",
  "sourceFileName": "main.py",
  "outputFileName": null,
  "interpreted": true,
  "arguments": null,
  "expectedOutputPath": "expected/output.txt"
}
